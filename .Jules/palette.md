## 2024-08-29 - Explicit vs Implicit Form Label Associations
**Learning:** Using structural proximity to imply input labels fails to meet the strict accessibility standards required. Even when a `<label>` element is positioned adjacently to an `<input>` field visually, screen readers and accessibility tools require a programmatic link to explicitly convey this relationship.
**Action:** When a visible label can be provided for an input or textarea element, explicitly pair the label to its corresponding input using a unique `id` on the input element, and a matching `htmlFor` attribute on the corresponding `<label>` element. When a visible label cannot be provided due to strict design constraints, provide an `aria-label` attribute on the element to describe its purpose to screen readers instead.
