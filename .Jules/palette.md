## 2025-02-23 - Form Accessibility Constraints
**Learning:** When adding explicit `htmlFor` and `id` bindings to `<label>` and `<input>`/`<textarea>` elements in this application, sometimes visible `<label>`s exist (e.g. `Contact.jsx`), but other times design constraints mandate placeholder-only inputs (e.g. `RentModal.jsx`). To maintain the strict rule against adding custom CSS to visually hide explicit `<label>`s, `aria-label` attributes must be applied directly to the inputs in placeholder-only designs.
**Action:** When improving form accessibility, always check if visible labels exist in the current UI design. If they do, use the standard `htmlFor` and `id` binding pattern. If they don't, use `aria-label` directly on the input element to avoid introducing new CSS classes for visually hidden labels.
