## 2024-09-09 - Accessible Form Labels Without Design Overhaul
**Learning:** Adding explicit visible `<label>` elements can sometimes violate strict visual design constraints or custom CSS rules if not originally accommodated in the UI. Relying on structural proximity for forms (like placeholders or implicit text adjacent to inputs) is bad for accessibility as screen readers need an explicit programmatic connection.
**Action:** When a design prevents adding a visible `<label>` and linking it via `htmlFor`, apply the `aria-label` attribute directly to the interactive elements (`<input>`, `<textarea>`, or range sliders) to maintain screen reader compatibility without altering the visual structure. When visible labels do exist, always link them explicitly using `htmlFor` on the label and matching `id` on the input.
