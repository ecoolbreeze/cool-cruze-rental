## YYYY-MM-DD - [Add accessible form properties]
**Learning:** For forms that use placeholders for the design system but do not contain visible `<label>` tags, we can supply an `aria-label` attribute to the input tags. In cases where the design uses visual `<label>` elements, we can explicitly add a `htmlFor` and an `id` that correspond to each other to enhance accessibility.
**Action:** Always check the form and inputs to see if they are properly given accessibility properties to allow screen readers and visually impaired users to use the form with ease.
