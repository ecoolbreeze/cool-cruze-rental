## 2026-09-10 - Form Accessibility with aria-labels
**Learning:** When visual design constraints prevent explicitly using visible `<label>` elements, adding `aria-label` directly to `<input>` or `<textarea>` elements improves form accessibility for screen readers without relying on visual changes.
**Action:** Use `aria-label` for forms where structural proximity is the only visual cue and visible labels are omitted.
