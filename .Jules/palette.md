## 2024-05-18 - Explicitly Linking Form Elements for Accessibility
**Learning:** I noticed a pattern in this application where forms either relied solely on structural proximity for associating visible `<label>` elements with their inputs (like in `Contact.jsx`), or relied completely on placeholder text without explicit visible labels due to design constraints (like in `RentModal.jsx`). This creates significant accessibility barriers for screen reader users who cannot easily associate the input with its intended purpose.
**Action:** Always explicitly link visible `<label>` elements to their inputs using `htmlFor` and `id` attributes. When visual design constraints prevent a visible `<label>`, always add an `aria-label` attribute directly to the `<input>` or `<textarea>` element to provide context for screen readers.
